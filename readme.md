# 个人世界模型库

## 1. 基于dreamerV3的Car Racing

### 项目结构

```
DreamBed/
├── train.py
├── readme.md
└── runs/                  运行时创建
    └── <run_id>/
        ├── config.json    本次实际生效的参数
        └── frames.png     如果选择保存三帧检查图
```


### 作战任务

1. 练习可读、易上手的软件设计。默认入口要简单，能找到配置、训练流程和结果。按训练入口、回放、世界模型、策略更新、评估的职责逐步拆分。配置集中管理，每次运行保存实际生效的参数。工程抽象要有具体用途，遇到真实需求时再加。
2. 用实现巩固世界模型理解。每次先讲清当前模块的输入、输出和预期，并用能手算的最小例子检查。重点看轨迹时间对齐、RSSM 的先验与后验、有观测重建和只给动作的多步预测、以及 λ-return 的正常结束和真实终止。抽象之处用具体赛车场景或几步小数字解释。
3. 规范实验记录和可视化。CarRacing-v3 是 benchmark，随机策略先做验收，后续考虑用 PPO 作为基线。主图横轴是累计真实环境交互步数，纵轴是独立评估的平均整局原始回报，算法使用同一组独立评估赛道。分开记录训练种子与评估赛道种子，并记录批量大小、序列长度、训练更新次数和运行设置。先保留每个训练种子的结果与原始记录，积累独立运行后再汇总均值及波动。
